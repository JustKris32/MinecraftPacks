Packshift

Move Minecraft modpacks between launchers.

Packshift converts modpacks between CurseForge, Modrinth and plain zip files. A CurseForge export only holds a manifest, a mod list and your overrides, so Packshift downloads every mod and builds a complete pack for you. Everything is read and built in this page. Only mod downloads and lookups go online.

  • .mrpack → .zipUnpack a Modrinth pack with every mod and config inside.
  • CurseForge → .zipTurn a manifest-only export into a full, ready-to-run zip.
  • .zip → .mrpackPackage an instance or CurseForge pack for Modrinth.
  • Inspect a packLook inside any pack and spot mods for the wrong version or loader.
  • HistoryFind the packs you opened and the mods inside them, kept on this device.
Relay settings off

CurseForge packs, and some mod hosts, cannot be reached straight from a web page. A relay forwards those requests. Use the local helper (node packshift-server.js, open the address it prints) or paste the address of your own Cloudflare relay. Modrinth packs and instance zips usually work without either.

Each mod in an .mrpack is a download link plus a checksum, so a zip built from one is only as complete as the download servers allow. Mods that Modrinth does not know about stay inside a new .mrpack as bundled files, so check that each license allows redistribution before you share the pack. In Chrome and Edge the result is written straight to the file you pick, so big packs do not need to fit in memory. Other browsers build the file in memory first.
